# Number Guesser

A simple Python number guessing game.

## Description

`num_guesser.py` picks a random number between 1 and 20 and prompts the player to guess it. After each guess, the script tells the player whether the guess is too low, too high, or correct.

## How to run

1. Make sure you have Python installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python num_guesser.py
```

## Gameplay

- Enter an integer between 1 and 20 when prompted.
- The game continues until you guess the secret number.
- The script displays the number of attempts once the correct guess is made.

## Error handling

If you enter a non-integer value, the game will prompt you to enter a valid number.
