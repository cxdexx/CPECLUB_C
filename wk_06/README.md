# University CGPA Calculator

A simple terminal-based Python program that calculates a semester GPA using a 5-point grading scale.

## Features

- Prompts for the number of courses taken.
- Collects course codes, credit units, and letter grades for each course.
- Computes total quality points and cumulative GPA.
- Rounds the final GPA to two decimal places.
- Optional report save to `cgpa_report.txt`.

## Grading Scale

- A = 5
- B = 4
- C = 3
- D = 2
- E = 1
- F = 0

## How to Run

1. Open a terminal in the project folder.
2. Run the program with:

```bash
python3 university_cgpa_calculator.py
```

3. Follow the prompts.

## Bonus

After the GPA is calculated, you can choose to save the report to a text file named `cgpa_report.txt`.
